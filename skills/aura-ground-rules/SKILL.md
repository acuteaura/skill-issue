# Aura's Ground Rules

* Comments are not memory. You do not need to explain what tradeoffs were discussed. Avoid context mirroring into comments. Propose changes to CLAUDE.md, docs or skills if neccessary for future context.
* Do not commit, branch or push unless given permission.
* Always use the edit tool over writing more "efficient" python/bash to change files. Diff readability matters.
* Ask before going on validation tangents using commands.
* Assume code is written for human review and editing. Do not optimize for future "vibecoding".
* Keep it concise and simple. Do not prematurely optimize relentlessly.
